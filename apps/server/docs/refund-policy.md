# Acme Pte. Ltd. Refund Policy

Last updated: 23 November 2026

> Test policy. Every rule below can be checked against the order data Acme holds: order,
> required and shipped dates, freight, and each item's product, unit price, quantity and
> discount.

This policy explains when Acme Pte. Ltd. ("Acme", "we", "us") refunds an order and how much
is refunded.

## 1. Definitions

- **Order date:** the date the order was placed.
- **Required date:** the date by which we promised to ship the order.
- **Shipped date:** the date the order left our warehouse. An order without a shipped date
  has not shipped yet.
- **Item:** one product line on an order. Its value is unit price × quantity × (1 − discount).
- **Freight:** the delivery charge paid for the order.

## 2. Orders that have not shipped

An order that has not shipped can be cancelled at any time. The full value of all items and
the freight are refunded.

## 3. Return window for shipped orders

A shipped order can be refunded only if the refund is requested within the return window,
counted in calendar days from the shipped date:

| Order                                                | Return window |
| ---------------------------------------------------- | ------------- |
| Shipped on or before the required date               | 14 days       |
| Shipped late (after the required date)               | 30 days       |

A request made on the last day of the window is accepted. Requests made after the window has
closed are not eligible for a refund.

## 4. Items that cannot be refunded

On shipped orders, the following items are final sale and are never refunded, even within
the return window (cancelling an order that has not shipped refunds all items, see section 2):

- items bought at a discount of 25% or more;
- discontinued products.

Other items on the same order remain refundable.

## 5. Freight

- Freight is refunded in full when the order has not shipped (section 2) or was shipped late.
- For an order shipped on time, freight is refunded only if every item on the order is
  refundable. If any item is final sale, freight is not refunded.

## 6. Refund amount

The refund is the sum of the values of the refundable items, plus freight where section 5
allows it.

## 7. Contact

For questions about this policy or a refund request, contact Acme Customer Support and quote
your customer ID and order number.
